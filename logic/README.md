## How to use this folder

Use `logic/` when you remember the syntax but not the idea. Use `modern/` or `legacy/` when you understand the idea but forgot how a language spells it.

Think of it as:

```text
logic/   = WHAT the program is doing
modern/  = HOW a modern language writes it
legacy/  = HOW an older language writes it
```
