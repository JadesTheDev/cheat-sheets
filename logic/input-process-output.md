# Input, Process, Output

Most programs can be reduced to three stages:

```text
INPUT → PROCESS → OUTPUT
```

## Input

Data enters the program.

Examples:

- Keyboard input
- A file
- A database query
- A sensor
- A web request

## Process

The program does something with the input.

Examples:

- Calculate a total
- Compare two values
- Search a list
- Sort data
- Convert a format
- Validate a password

## Output

The program produces a result.

Examples:

- Text on screen
- A returned value
- A saved file
- A database update
- A network response

## Example

Problem: calculate gross pay.

```text
INPUT
hours = 8
rate = 20

PROCESS
pay = hours × rate

OUTPUT
160
```

## Why this matters

When a program feels confusing, identify these three pieces first:

1. What information do I start with?
2. What must happen to that information?
3. What result should come out?

If one of those answers is unclear, the code will usually be unclear too.
